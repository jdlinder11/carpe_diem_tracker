# Carpe Diem Habit Journal

A free, journal-style habit tracker in one file (`index.html`). No build step, no backend. Each visitor's habits are saved in their own browser.

## Put it on GitHub Pages

1. Create a new public repository on GitHub, for example `carpe_diem_tracker`.
2. Keep `index.html` and the `guides` folder at the root of the repository.
3. Open Settings > Pages. Under "Build and deployment", set Source to "Deploy from a branch", pick `main` and `/ (root)`, then Save.
4. After a minute or two the site is live at `https://jdlinder11.github.io/carpe_diem_tracker/`.

To use your own domain later, add it under Settings > Pages > Custom domain and follow GitHub's DNS steps.
